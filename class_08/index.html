第8回 フォローアップ・学習テキスト

人が世界を理解し成長する仕組み
―愛着の基盤から認知の発達（ピアジェ）、そして学びを支える関わり（ヴィゴツキー）まで―

本テキストは、第8回目の発達心理学の授業を休んだ人が、授業で扱った「愛着（アタッチメント）の重要性」「感覚・知覚の万能性とシナプス刈り込み」「ピアジェの認知発達理論（感覚運動期・前操作期・保存概念）」「認知葛藤と同化・調整のメカニズム」、そして「ブルーナーの発見学習とヴィゴツキーの発達の最近接領域（ZPD）」について体系的に学習できるように作成されたフォロー教材です[cite: 4, 5]。

1. 【プロローグ】心の安全基地と愛着（アタッチメント）

講義の冒頭では、人として生きていくための根本となる「人間関係の基盤（愛着）」について確認しました[cite: 4, 5]。

👑 皇帝フリードリヒ2世の悲しい実験[cite: 4, 5]

13世紀の皇帝フリードリヒ2世は、「赤ん坊に一切話しかけず、目も合わせず、ミルクとオムツ替えだけを与えて育てたら、人類最初の言語は何を話すか？」という実験を行いました[cite: 4, 5]。結果は、言葉を話す前に赤ちゃん全員が死亡してしまったのです[cite: 4, 5]。

人はただ栄養を摂るだけでは生きていけず、目を合わせ、微笑みかけられるといった「愛情ある情緒的関わり」が命の維持に不可欠であることを示す歴史的エピソードです[cite: 4, 5]。

■ プロトタイプ（心の基本型）[cite: 4, 5]

精神科医ジョン・ボウルビィは、特定の人物と結ぶ強い情緒的絆を「愛着」と呼びました[cite: 4, 5]。幼少期に適切な愛着が育まれると、「困ったときに人は助けてくれる」「世界は安全だ」という基本的人間信頼（プロトタイプ）が心の中に形作られます[cite: 4, 5]。

■ 逆境的小児期体験（ACE）と脳内ホルモン[cite: 4, 5]

幼少期に虐待やネグレクトなどの逆境（ACE）を体験すると、愛着から分泌される安心ホルモン「オキシトシン」が不足します[cite: 4, 5]。その寂しさや不安を埋めるため、将来的に過食、依存症、危険な行動に走りやすくなり、平均寿命や健康状態にも深刻な影響を及ぼすことが分かっています[cite: 4, 5]。

2. 【第1章】世界に適応する脳（知覚の万能性とシナプスの刈り込み）

赤ちゃんは、大人には真似できない「驚くべき万能の能力」を持って生まれてきます[cite: 4, 5]。

🌐 赤ちゃんは「世界市民」として生まれてくる[cite: 4, 5]

生後まもない乳児は、日本語にはない英語の「R と L」の発音の違い、韓国語の母音の違い、さらには「一頭一頭のお猿さんの顔の違い」まで見分ける能力を持っています[cite: 4, 5]。地球上のどの環境に生まれても生きられるよう、生まれた瞬間はあらゆる刺激を識別できる「万能の脳」を用意しているためです[cite: 4, 5]。

✂️ シナプスの刈り込み（Pruning）[cite: 4, 5]

成長するにつれて使わない無駄な脳の配線（シナプス）を削ぎ落とし、自分が生きる環境に必要な能力（日本語の理解など）に脳の資源を集中させる合理的な仕組みを「シナプス刈り込み」と呼びます[cite: 4, 5]。

💡 発達障害（ASD等）とシナプス刈り込み[cite: 4, 5]

自閉スペクトラム症（ASD）などの神経発達の個性は、この「シナプス刈り込み」の進み方の違い（刈り込みが少なく情報が過剰に入りやすい等）と関連している可能性が指摘されています[cite: 4, 5]。ある状態を単に「悪いこと」と非難するのではなく、「そういう前提（個性）」として捉え、「どうすれば本人の生きづらさや苦しみが減るか」を考える視点が大切です[cite: 4, 5]。

3. 【第2章・第3章】子どもはどうやって世界を知るのか？（ピアジェの認知発達理論）

ジャン・ピアジェ（Jean Piaget）は、子どもは大人の教えを丸暗記するのではなく、**「自分自身で環境に働きかけ、試行錯誤しながら世界を理解する知識を作り上げていく（構成主義）」**と考えました[cite: 4, 5]。

🍼 第Ⅰ期：感覚運動期（誕生〜2歳頃）[cite: 4, 5]

見ること、触ること、吸うことなどの「感覚」と「運動」を通して世界を理解する時期です[cite: 4, 5]。

・第一次循環反応（1〜4ヶ月頃）： 自分の身体を使った偶然の行動（指しゃぶり等）を繰り返す[cite: 4, 5]。

・第二次循環反応（4〜8ヶ月頃）： ガラガラを振ると音が鳴るなど、外の世界のモノに変化を起こす行動を繰り返す[cite: 4, 5]。

・ものの永続性の獲得（8〜12ヶ月頃）： 目の前のオモチャを布で隠しても「布の下に存在し続けている」ことを理解して探せるようになる[cite: 4, 5]。

・第三次循環反応（12〜18ヶ月頃）： あえてやり方を変えて「こうしたらどうなるだろう？」と試行錯誤（実験）を楽しむ[cite: 4, 5]。

🎈 第Ⅱ期：前操作期（2歳〜7歳頃）[cite: 4, 5]

言葉やシンボルを使って考えるようになりますが、まだ直感や見た目に大きく左右される時期です[cite: 4, 5]。

・アニミズム（生命観）： 「すべてのものに命や心がある」と考える（例：「時計は動くから生きている」）[cite: 4, 5]。

・自己中心性（三山課題）： 他人の視点に立って物事を見ることが難しく、「向かい側に座っている人からも自分と同じ風景が見えているはずだ」と思い込む[cite: 4, 5]。

・保存概念の不成立： 同じ量の水を細長いコップに入れ替えると「背が高い方が水が多い！」と答えたり、ボールの間隔を広げると「青いボールの方が多い！」と感じてしまう（見た目に騙される）[cite: 4, 5]。

4. 【第4章】「あれ？」という不完全さが人を成長させる（認知葛藤と同化・調整）

子どもはどのようにして「見た目の騙され」を乗り越え、論理的な思考を獲得していくのでしょうか[cite: 4, 5]。ピアジェはそのメカニズムを**「同化」「調整」「均衡化」**で説明しました[cite: 4, 5]。

🔄 子どもの認知発達のステップ[cite: 4, 5]

1. 既存の認知構造（シェマ）： 例「動くものはすべて生き物だ！」[cite: 4, 5]

2. 同化（Assimilation）： 目の前の現象を自分のシェマに当てはめる（例「時計はカチコチ動くから生き物だ！」）[cite: 4, 5]。

3. 認知葛藤（Cognitive Conflict）★超重要！：
自分のシェマでは説明できない矛盾に直面する（例「えっ？ 時計は動くけどご飯食べないし赤ちゃんも生まないぞ…『あれ？』」）[cite: 4, 5]。

4. 調整（Accommodation）： 矛盾を解決するために自分のシェマを書き換える（例「『自力で動き、生命活動をするもの』が生き物なんだ！」）[cite: 4, 5]。

5. 均衡化（Equilibration）： より高度で論理的な認知構造へとレベルアップする[cite: 4, 5]！

💡 認知葛藤（Cognitive Conflict）とは？[cite: 4, 5]

自分の持っている既存の考え方（シェマ）では、目の前の事実や現象を説明できなくなったときに生じる「心理的な違和感・モヤモヤ（不均衡状態）」のことです[cite: 4, 5]。この「あれ？」という葛藤を経験し、自分で乗り越えようとするときに初めて、脳は新しい論理的な思考へと再構成を遂げます[cite: 4, 5]。

5. 【第5章】学びを深める関わり（発見学習と発達の最近接領域）

ピアジェやヴィゴツキーの理論は、教育や大人の関わり方に大きなヒントを与えています[cite: 4, 5]。

■ 単に教えても知識は消えてしまう（素朴概念と学力剥離）[cite: 4, 5]

学校で暗記させられた知識は、数年経つと忘れて直感的な思い込み（素朴概念）に戻ってしまう現象（学力剥離）が起きます[cite: 4, 5]。

■ ブルーナーの「発見学習」[cite: 4, 5]

大人が答えを教え込むのではなく、子ども自身に「あれ？」という認知葛藤を体験させ、自分で知識の生成過程をたどって発見させる学習が最も深い学びに繋がります[cite: 4, 5]。

■ ヴィゴツキーの「発達の最近接領域（ZPD）」[cite: 4, 5]

子どもの発達には「1. 一人でできること」「2. 手助けがあればできること（ZPD）」「3. まだ絶対できないこと」の3領域があります[cite: 4, 5]。

大人の役割は、子どもががんばっていることがどちらなのかを見極め、**「発達の最近接領域（ZPD）」に対して適切なヒントや足場かけ（スキャフォールディング）を行い、見守ること**です[cite: 4, 5]。
